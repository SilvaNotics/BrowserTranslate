# 译境 v0.1.0 实施记录

目标：WXT + React + TypeScript Chrome MV3 扩展，供应商管理、划词、整页、截图双识别和 Exa MCP 联网解释。交付开发者加载包及公开 GitHub 仓库。

## 任务

- [x] 配置、端点适配与弹窗/设置页
- [x] 划词与联网解释
- [x] 整页翻译、停止与恢复
- [x] 截图裁剪与本地/视觉识别
- [x] 单元与浏览器验证

发布方式：公开仓库 `BrowserTranslate`，标签 `v0.1.0` 触发 GitHub Actions 验证并生成 Release。

## 决策

- 空仓库没有基准提交，直接在独立分支 codex/browser-translate 工作，不创建额外工作树。
- 首版普通 HTTP/HTTPS 页面；默认三个功能开关启用、简体中文、双语、本地 OCR。
- UI 与后台共享 src/core/types.ts 和 src/core/rpc.ts，密钥不传给内容脚本。
- 独立界面任务交给一个子代理，控制器处理后台与内容脚本，避免写同一文件。
- 最低 Chrome 124，匹配模型请求使用的 AbortSignal.any。
- 仅译文模式隐藏但保留原文节点，并提供原文链接入口；点击转交原节点，以保留网站原有点击处理。
- 页面路由变化会恢复原文、取消旧任务并重建网页浮层；虚拟列表复用节点时重新翻译。
- 不接收网页脚本合成的快捷键和浮层操作，防止未经用户操作发送模型请求。

## 验证记录

- Vitest 覆盖凭据隔离、多供应商与手动模型、兼容端点、自定义路径、认证/限流/格式错误、不可达与取消、批量响应校验、引用过滤、高 DPI 裁剪、Ctrl 状态、隐藏段落、节点更新、停止恢复和 OCR 取消。
- Playwright 在独立 Chromium 配置中加载生产扩展，覆盖设置、连接、划词、拖动边界、合成事件拦截、双语与仅译文链接、动态段落、SPA 路由、恢复、框选取消、实际本地 OCR、视觉图片尺寸、来源转义与限流降级。
- 本地 OCR 测试使用真实随包 Tesseract，中英文资源不依赖 CDN；断言模型请求仅含识别文字。
- 视觉识别测试断言上传图片为实际裁剪后的 396 × 86 PNG，随后翻译请求没有图片。
- Exa 免密钥 MCP 已实连搜索，成功返回可引用来源；端到端测试中的 Exa 场景使用协议模拟以稳定覆盖错误路径。
- 模型接口使用本机模拟服务，尚未使用个人供应商密钥进行真实模型翻译。
- 外部来源与模型输出仅作为文本展示；提示注入无法执行页面代码，但模型解释仍需用户结合出处判断。
